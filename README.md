# Atendevet nodes for n8n

Official n8n nodes for [Atendevet](https://www.atendevet.com.br), the management platform for veterinary clinics, hospitals and home-visit vets in Brazil.

- **Atendevet Trigger** starts a workflow when something happens in the clinic: an appointment is booked, a payment is received, a vaccine is due, a document is signed, a new CRM lead arrives and about 40 other events.
- **Atendevet** reads clinic data in a workflow step: patients, clients (legal guardians), sales, sales reports, CRM leads, document templates and signature status. It also works as a tool for the n8n AI Agent.

## Installation

Follow the [installation guide](https://docs.n8n.io/integrations/community-nodes/installation/) in the n8n community nodes documentation and install `@atendevet/n8n-nodes-atendevet`.

## Credentials

The nodes use an Atendevet API key.

1. In Atendevet, open **Perfil → Configurações → Integrações** (Profile → Settings → Integrations) and create a key. Choose **Agente de IA** (AI agent): the key comes with every read permission you can grant, including *Receber avisos de eventos* (event notifications).
2. Copy the key (it starts with `avk_`). It is shown only once.
3. In n8n, create an **Atendevet API** credential and paste the key. Keep **Base URL** as `https://api.atendevet.app`.

Each key only sees the clinic and the permissions it was created with. You can revoke it in Atendevet at any time.

## Atendevet Trigger

Choose one or more events. When the workflow is activated, the node subscribes to them in Atendevet; when it is deactivated, the subscription is removed. Subscriptions created by n8n are named `n8n: <workflow name>` and are listed in Atendevet under **Perfil → Configurações → Integrações**.

Every delivery is signed with HMAC-SHA256 (`X-Atendevet-Signature`) using a secret generated by the node, and the node rejects deliveries with a wrong signature.

Each execution receives the event envelope:

```json
{
  "id": "6f1c…",
  "evento": "agendamento.criado",
  "criadoEm": "2026-11-24T13:05:00Z",
  "teste": false,
  "versao": 1,
  "dados": { "…": "event data" }
}
```

The event list in the node shows what data each event carries.

To test, click **Listen for test event** and then click **Test** on the `n8n:` webhook in Atendevet. Atendevet sends a sample of each subscribed event, with `"teste": true`.

Atendevet only delivers to public `https` addresses. On a self-hosted n8n, set `N8N_WEBHOOK_URL` (`WEBHOOK_URL` in older versions) to its public https address.

## Atendevet operations

| Resource | Operations |
| --- | --- |
| Client | Get, Get Address, Get Many |
| Document Signature | Get Status |
| Document Template | Get, Get Many |
| Lead | Get, Get Funnel, Get Many |
| Patient | Get, Get History, Get Many, Get Medical Background, Get Recent, Get Weights |
| Sale | Get, Get Items, Get Many |
| Sales Report | Get Summary, Get by Client |

Each operation needs the matching permission on the key (for example, *Consultar pacientes (pets)* for the Patient resource). A missing permission returns a 403 error. The full reference of the API behind these operations is at [api.atendevet.app/scalar/integracao](https://api.atendevet.app/scalar/integracao).

## AI agents and MCP

Atendevet also has an official MCP server at `https://api.atendevet.app/mcp`, with around 50 tools: agenda, patients, hospitalization, health records, quotes and more. Write tools create **proposals** that someone at the clinic approves in Atendevet, unless the clinic allowed direct recording.

To use it in an n8n AI Agent, add n8n's built-in **MCP Client Tool**:

1. **Endpoint**: `https://api.atendevet.app/mcp`
2. **Server Transport**: HTTP Streamable
3. **Authentication**: Header Auth, with name `X-Api-Key` and the Atendevet key as value (the key needs *Ativar o agente de IA*)

The **Atendevet** node can be added to the same agent as a tool.

## Example workflows

The [`workflows`](workflows) folder has ready-made workflows you can import in n8n:

- Daily sales summary sent to Telegram
- New appointment copied to Google Calendar
- Vaccines due added to a Google Sheets follow-up list
- Payment received announced in Slack
- Clinic assistant: AI Agent with the Atendevet MCP server
